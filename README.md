"# AI ML Learning Practice

This repository is a hands-on practice workspace for learning foundational concepts in Artificial Intelligence and Natural Language Processing (NLP) using Python and Jupyter notebooks.

The goal is to explore core NLP techniques, experiment with text preprocessing, and build a stronger understanding of how language models and text analysis pipelines work.

## Repository structure

- `nlp.ipynb` — main NLP learning notebook
- `test.ipynb` — scratch / experimental notebook
- `NLP_practice/` — focused NLP exercises and mini-practice notebooks

### NLP practice notebooks

- `practice_tokenizer.ipynb` — tokenization examples using NLTK
- `practice_stemming.ipynb` — stemming with Porter Stemmer
- `praactice_leemitization.ipynb` — lemmatization exercise (filename preserved from original practice work)
- `practice_regix.ipynb` — regular expression examples for text processing
- `practice_1.ipynb` — introductory NLP practice notebook
- `practice_2.ipynb` — additional NLP exercises and experiments

## Topics covered

- Text preprocessing
- Tokenization
- Sentence splitting
- Stemming and lemmatization
- Stopword removal

- Basic NLP workflow practice in Python

## How to use this repository

1. Create and activate a virtual environment.
2. Install the required Python packages.
3. Open the notebooks in Jupyter Notebook or JupyterLab.
4. Run the cells in order to follow the NLP exercises.

Example:

```bash
conda create -n nlp python=3.11
conda activate nlp
pip install numpy nltk pandas matplotlib spacy textblob vaderSentiment transformers scikit-learn gensim seaborn torch ipywidgets chardet jupyterlab notebook
jupyter lab
```

## Notes

This repo is intended for learning and experimentation rather than production deployment. It is best suited for beginners practicing NLP concepts in a notebook-based environment.
